# Kaif — Solidity Verifier Brief

> **Role:** Solidity verifier integration and contract testing
> **Primary directories:** `contracts/`, `test/`

---

## 🎯 Your Mission

You deploy and wrap the auto-generated ZKP verifier in a user-friendly Solidity contract. You ensure that valid proofs pass and invalid proofs are rejected on-chain (local testing via Remix or Hardhat).

---

## 📋 What You Must Build

### 1. Wrapper Contract (`contracts/ScholarshipVerifier.sol`)

Wraps the auto-generated `Verifier.sol` (produced by Tufel via snarkjs) with a clean interface.

See `docs/INTERFACE_CONTRACT.md` §4 for the exact interface. Key requirements:

- Import and call `Verifier.verifyProof()`
- Check that `input[0] == 1` (eligible signal)
- Emit a `VerificationResult` event with the caller's address, eligibility, and timestamp
- Return `true` only if the proof is valid AND the student is eligible
- **Do not** store or emit the student's income or credential details

### 2. Contract Tests (`test/contract_tests.js` or via Remix)

Test with real proof artifacts (from Tufel):

| Test Case | Expected Result |
|---|---|
| Valid proof, eligible student | `verifyScholarship` returns `true` |
| Valid proof, ineligible student | `verifyScholarship` returns `false` (input[0] = 0) |
| Tampered proof (modified pi_a) | Transaction reverts or returns `false` |
| Wrong public signals | Transaction reverts or returns `false` |
| Empty/malformed input | Transaction reverts |

## 💡 Implementation Tips

### Using Remix IDE
1. Open [Remix](https://remix.ethereum.org/)
2. Create `Verifier.sol` and `ScholarshipVerifier.sol` in the File Explorer
3. Compile with Solidity 0.8.x
4. Deploy `Verifier` first, then `ScholarshipVerifier` with the Verifier's address
5. Call `verifyScholarship` with proof data from Tufel's output

### Using Hardhat (alternative)
```bash
npx hardhat compile
npx hardhat test
```

### Converting proof.json to Solidity calldata
snarkjs can generate Solidity-compatible calldata:
```bash
snarkjs groth16 exportsoliditycalldata public.json proof.json
```
This outputs the exact `a`, `b`, `c`, `input` arrays to paste into Remix.
